Audit a website

Read-only: Tapp renders up to six pages and reports what is broken as served — dead controls, broken images and links, failed requests, layout that scrolls sideways on a phone. Nothing is clicked, typed or submitted, so it is safe on production or a site you do not own. No release verdict without source.

Your code stays on this machine.Exploration, replay and merge decisions are deterministic and need no API key. This machine must stay open while a run is in progress.
