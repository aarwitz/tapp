What tapp does

tapp opens web pages in a browser we run, looks at them, and reports what it finds. Signed in, it will also click, type, and sign in to applications using test accounts you give it, and replay journeys you keep.

Only point it at applications you are allowed to test

This is the one rule that matters. By starting a run you confirm you own the application, or have permission from whoever does, to have an automated browser visit and interact with it.

Without an account, tapp only ever reads a site: it never presses, types or submits. Signing in is what unlocks clicking, which is why clicking requires an account.
