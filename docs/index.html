Platforms

Browser first. One release contract across every integration.

The browser is the launch experience and web is the first market lane. CLI, MCP, VS Code, iOS, Android, desktop Coverage, and CI use the same repository artifacts and evidence protocol; legacy desktop import/run orchestration is still being migrated.

📱

Browser Release Studio

Import an owned checkout, build and explore the real web app, inspect its UI Map, review business contracts, validate without AI, establish a baseline, and preview CI.

🌐

Web — launch lane

Built on Playwright: your agent already has browser hands; tapp adds autonomous exploration and detectors for uncaught exceptions, failed requests, dead buttons, broken links, and error pages.

🖥

Native and agent integrations

iOS XCUITest, Android UIAutomator, CLI, MCP, VS Code, desktop, and the GitHub Action retain the shared Flow, Task, contract, map, baseline, and gate protocol.

Local and inspectable

Explore autonomously. Commit only what matters.

Tapp can discover broadly, then distill the highest-value behavior into reusable Tasks and reviewable business contracts. The deterministic suite runs in CI without a model or API key.

The verdict you can trust

Deterministic. No LLM in the run loop.

tapp explores like a user and detects crashes, failed sign-ins, dead buttons, stuck loading screens, navigation dead ends — and on web, uncaught exceptions, failed requests, and broken links — then commits to a verdict. Same evidence in, same verdict out. A shallow run is never ready. Absence of findings is not a pass.

🟢 ready

Genuinely explored, no blockers found.

🟡 caution

Issues to review, or the run couldn't see enough.

🔴 blocked

A release-blocking issue was found.

The complete product loop

From checkout to a merge decision.

Start locally in the browser, approve the guarantees that define a safe release, and install the same engine as a portable GitHub Action. Every PR answers one question with evidence: did this break important behavior that worked in the reviewed baseline?

  • Builds/starts and maps the owned real web application
  • Composes reusable Tasks into business-level release contracts
  • Blocks on failed critical contracts, crashes, and new high/critical regressions
  • Shows exact coverage boundaries, screenshots, and deterministic replay evidence
